# 🧠 BrainFizz – Interactive Quiz Application

BrainFizz is an interactive quiz application that allows users to test their knowledge through three difficulty levels: Easy, Medium, and Hard.

## ✨ Features

- **Three Difficulty Levels:** Easy, Medium, and Hard.
- **Multiple-Choice Questions:** 5 questions in each difficulty level.
- **Countdown Timer:** 10 seconds for each question.
- **Instant Feedback:** Displays correct and incorrect answer feedback.
- **Sound Effects:** Different sounds for correct and incorrect answers.
- **Score Tracking:** Displays the final score after completing the quiz.
- **Play Again:** Return to the home screen and play again.

## 🛠️ Technologies Used

- HTML5
- CSS3
- jQuery

## 🚀 How to Run

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Ensure the sound files are present inside the `sounds` folder.
4. Open `index.html` in a web browser.
5. Select a difficulty level and start the quiz.

**Note:** An internet connection is required to load jQuery from its CDN.

## 🎯 Project Objective

BrainFizz demonstrates the use of jQuery for DOM manipulation, event handling, and interactive web application development.
